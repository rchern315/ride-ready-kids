# Ride Ready

A mobile-friendly Next.js starter for teaching kids and teens ages 7–17 about safe riding on bicycles, kick scooters, and electric scooters. It starts with general safety education and leaves a data-driven home for state-specific rules.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy to Vercel

Import this project into Vercel as a new project. Vercel detects Next.js automatically; use the default build command (`npm run build`) and output settings.

## Product decisions

- Learning bands: 7–10, 11–13, and 14–17. These are teaching groupings, not legal age rules. Supervision and readiness vary by child and situation.
- The state picker is scaffolding only. It must not imply that state laws have been researched. Add verified state-by-state rules before describing a state's age limits, sidewalk access, roadway access, equipment requirements, or e-scooter restrictions as law.
- The red-light practice is an interactive, simplified demonstration. It teaches a cautious sequence and is not a substitute for local rules or adult instruction.

## Content sources used for the starter

- NHTSA, Bicycle Safety: https://www.nhtsa.gov/road-safety/bicycle-safety
- NHTSA, Learn to Bike Safely: https://www.nhtsa.gov/bicycle-safety/learn-bike-safely
- FHWA, Bicycle Safer Journey (elementary school video): https://www.youtube.com/watch?v=dkoVxBnnGko
- PeopleForBikes, State-by-state electric bicycle laws (research starting point, not a substitute for primary state sources): https://www.peopleforbikes.org/electric-bikes/state-laws
